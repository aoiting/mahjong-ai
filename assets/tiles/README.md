# 麻雀牌圖像

呢個資料夾嘅牌圖用嚟喺介面顯示真實牌面（取代 `1m`、`5p` 呢類文字代碼）。

## 來源與授權

- 來源：<https://github.com/FluffyStuff/riichi-mahjong-tiles>
- 授權：**CC0 1.0（公有領域）**，可自由使用、修改及再分發。

## 想用自己嘅牌圖？

直接覆蓋同名 PNG 就可以，唔使改程式碼。檔名規則：

| 代碼 | 檔名 | 代碼 | 檔名 |
|---|---|---|---|
| 1m–9m | `Man1.png`–`Man9.png` | 1p–9p | `Pin1.png`–`Pin9.png` |
| 1s–9s | `Sou1.png`–`Sou9.png` | 1z | `Ton.png`（東） |
| 2z | `Nan.png`（南） | 3z | `Shaa.png`（西） |
| 4z | `Pei.png`（北） | 5z | `Haku.png`（白） |
| 6z | `Hatsu.png`（發） | 7z | `Chun.png`（中） |

建議用透明背景 PNG，高度約 600–800 px，比例 3:4。
